# 数据库

`db/migrations` 中的迁移文件定义了 RouteFrom 初始的 Postgres/PostGIS 数据模型。连接 Neon 时，应使用直连地址，并按照文件名顺序执行迁移。

数据模型有意将以下内容分开保存：

- 不可修改的上传数据集；
- 标准化后的 GPS 定位点；
- 派生出的地点、停留记录、轨迹段和行程；
- 数据处理运行记录及算法版本；
- 保存的地图视图配置和生成资产。

原始 CSV 文件以及生成的二进制或 JSON 资产不直接存入 Postgres。数据库只记录这些私有文件在本地存储或对象存储中的键值和相关元数据。

身份认证方式确定后，再添加认证集成和行级安全策略（RLS）。在此之前，数据库只能由服务端访问，不能将数据库连接信息暴露给浏览器前端。
